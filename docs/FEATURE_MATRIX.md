# 功能清单对照（M / P1 / P2）

> 产品原则（用户 2026-11-14 指示）：**主页面为主，菜单辅助**。下面两行是当时（音源只有 B 站）的表述；现在音源由用户配置（见 [SOURCE_SPEC.md](SOURCE_SPEC.md)），表里提到 UP 主、分区等 B 站概念的条目只在外部 B 站插件里成立。
> 主页面 = 完整播放器：空闲态是在线首页（搜索/推荐/链接直开），播放态是歌词；
> 菜单栏只放"快速操作"（账号、音质、缓存、电台、收藏、歌单）。

图例：✅ 已完成并验证 · 🟡 部分完成（说明见备注）· ⬜ 未做 · 🔒 平台限制
