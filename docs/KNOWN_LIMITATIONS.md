本机 `security find-identity -v -p codesigning` 返回 `0 valid identities found`。现有 `dist/SpatialLyricsPlayer.app` 是 ad-hoc 签名，`spctl --assess --type execute` 拒绝，无装订公证票据。DMG 校验与 App 签名完整性通过不代表系统允许公开分发。

- Developer ID 签名、公证、下载后的干净安装：未完成。
- XCUITest：签名受阻，未执行；不能声称 UI 自动化通过。
- 小组件 App Group / App Intent、开机启动注册：正式签名环境未验证。
- 构建仅支持 Apple Silicon arm64，最低 macOS 14；没有 Intel 产物与 Intel 验收。
- App Store 与独立分发版的功能差异、审核与更新通道尚未完成。

## 3. 插件与 HLS 的边界

- **第三方 JS 尚无可强制中断的执行时限。** 同步死循环仍可能阻塞插件导入与启动恢复。Swift 等待超时无法终止已经运行的 JavaScript；根治需要独立可终止进程。计时器修复不等于解决同步死循环。
- `allowedDomains` 为空或含 `"*"` 时按现有音源规范允许任意 HTTP/HTTPS 域；不能把该配置解释成严格域名隔离。地址检查不是完整的 DNS 解析与 DNS rebinding 防护。
- 插件 / 模板 ID 清洗碰撞、订阅导入的 `file://` / 内网访问与递归、普通插件 API 响应大小 / 并发边界仍需继续收口（审计 P2-11…P2-13）。HLS 的响应和并发限制不覆盖这些 API。
- HLS 本机代理仅监听 `127.0.0.1`，使用会话独立路由与 HMAC 认证；每次上游请求与重定向检查域名和联网开关。每资源响应上限 16 MiB，播放列表上限 1 MiB，上游并发上限 8。
- HLS 暂不支持 `EXT-X-CONTENT-STEERING`、`EXT-X-DEFINE` 动态变量、非 HTTP/HTTPS 密钥 URI。遇到这些入口拒绝加载，不退回外网直连；FairPlay 等 DRM 不在支持范围内。
- HLS 支持相对地址、多级列表、常见 URI 属性与单段字节范围；本机回环链路已用真实 AVPlayer 静音播放验证。正式 App Sandbox 签名环境与大规模真实曲库兼容仍待验证。
- 主应用新增 `network.server` entitlement 供本机 HLS 代理使用；实现不绑定公网接口。详见 [PERMISSIONS_AND_SANDBOX.md](PERMISSIONS_AND_SANDBOX.md)。

## 5. 真机与体验验收缺口

- 真实媒体键、控制中心联动、耳机物理拔插、睡眠 / 唤醒、多屏热插拔与会议应用前台遮罩仍缺人工完整验收。
- VoiceOver 朗读、全量键盘焦点顺序，以及 Reduce Motion / Reduce Transparency / 提高对比度的实机表现尚未完整走查。
- 首次启动到配置音源、播放切歌、离线、重启恢复、三档切换需要使用最终安装包再走一次；源码单测不能替代最终安装验收。
- 设置恢复需要重启才全部生效；诊断导出保存面板、Finder/Dock 拖放、隐藏 Dock 后全部入口等缺少最终包完整走查。
- 性能已有局部 Release 采样；万首曲库、长时间播放内存与整机能耗尚无完整 soak test。

## 6. 沉浸模式

详见 [IMMERSIVE_MODE.md](IMMERSIVE_MODE.md)。仍缺 2× 屏四场景全屏画质复核、全屏真实点击切回普通模式、更多音乐类型与白底极简封面的覆盖。一次全屏在切走应用后自行退出的原因仍未复现确认。

节拍自由、无鼓歌曲不一定出现节拍波，这是置信度门控的设计行为；场景背景会比纯色多耗电。完整播放器不参与自动避让，也是设计行为。

## 7. FLOW Voice

详见 [FLOW_VOICE.md](FLOW_VOICE.md)。默认关闭，不随包提供模型；底座与可运行音色支持按需联网获取。

- 已完成短音频原生 ONNX 端到端合成、`hubert_base.onnx` + `高松灯` 真机全曲 `.m4a` 生成与原曲↔AI 互切实测；**更多曲风伴奏分离与 `v1` / `32kHz` / `48kHz` 社区音色包广度试听仍缺全面人工验收**。
- 社区 `.pth` / `.index` 仍需仓库离线工具转为 `.voicepack` / `.onnx` + `.f32bin`，App 不直接执行 pickle 权重。
- 音色管理面板、在线检索下载与完全卸载仍缺最终正式签名包的完整辅助功能（VoiceOver）与首次安装走查。
- 一次只转换一个任务（有意设计）。生成完成时若 AI 开关打开且正在播这首歌，会就地切到 AI 版并保留进度；搜索、切歌不会自动开始转换，只在用户点「生成并播放 AI 版」时生成。
- 精选卡片的中文名依赖系统翻译（macOS 15+）：首次需要用户同意下载语言包，拒绝或在 macOS 14 上保持英文名（通用词如「女声 1」不受影响）。
- 底座模型的实网整链下载（三个文件、几百 MB）只有模拟网络的单元测试；签名沙盒包里读取 `~/Downloads/FLOW-VoicePacks`（下载目录只读权限）也未实测。

## 8. 当前发布定位

当前适合继续准备小范围 Beta；正式公开发布仍需签名公证、最终包用户路径验收，以及对剩余代码风险逐项作出修复或明确的首发范围决定。通过 `verify.sh` 表示工程门禁通过，不等于上述所有发布条件已经满足。
