## 二、发现的问题

### 问题 1（严重）：播放器左下角「接下来」显示错误的下一首

**现象**：播到队列第 5 首时，左下角「接下来」显示 `01 英雄主义`——那是队列**第 1 首、已经播过的歌**；「还有 19 首」也把已播的算进去了。

**原因**：`ExpandedPlayerView.queuedItems` 用 `items.filter { $0 != currentID }`——排除了当前曲，却保留了它**前面**的曲目。

**修复**：抽出 `UpNextPlanner`，按「手动插播（后进先出）→ 稍后播放 → 当前曲之后」排序。
`UpNextPlannerTests` 5 条覆盖：中间/队首/队尾/无当前曲/手动插播顺序。

**截图**：`docs/evidence/walkthrough-upnext-bug.png`（截图已从公开仓库移除）（播放「全世界都喜欢你」时显示「01 英雄主义」）。

### 问题 2（严重）：播放模式 / 随机播放不持久化

**现象**：切到「列表循环」→ 退出 → 重新打开，又回到「顺序播放」。

**原因**：`PlaybackEngine.cycleRepeatMode()` 与 `toggleShuffle()` 只改了内存里的 `queue`，
**没有 `broadcastState()`**——而持久化、控制中心、队列界面都订阅那条状态流。
同一个类里 `setRepeatMode()` 是广播的（还写了注释说明为什么必须广播），这两个方法漏了。

**修复**：三处补上广播——`cycleRepeatMode()`、`toggleShuffle()`、`restoreRepeatMode()`；
并让 `MorphWindowController.applyPlayback` 同步 `model.repeatMode / isShuffling`
（此前只有打开队列抽屉才会刷新播放条上的模式标签）。
`PlaybackModeBroadcastTests` 3 条验证状态流会发出更新。

**实测复验**：切到「单曲循环」→ 退出 → 重新打开 → 仍显示「单曲循环」。

### 问题 3（中）：收藏夹空态指引指向不存在的东西

**现象**：未登录时提示「收藏夹需要登录 B 站（**右上角地球** → 扫码登录）」——
界面里根本没有地球图标，用户照着找会找不到。

**修复**：改成「（设置 → 在线音乐 → 登录，扫码即可）」，与真实入口一致。
`GuidanceWordingTests` 2 条防止回退。

## 三、体验上的小摩擦（未改代码，供决策）

1. **抽屉打开时会盖住顶部工具栏**：队列/资料库/快捷设置三个按钮被抽屉遮住，
   想切换面板必须先点抽屉右上角关闭。可以接受，但会让用户以为按钮消失了。
2. **播放器会显示 B 站视频简介**：例如「感谢以下粉丝投喂的30元档位充电：@…」，
   在音乐播放器里属于噪音。建议只在简介短于一定长度时显示，或干脆不显示。
3. **同一首歌的标题在播放器与「最近」列表里可能短暂不同**（权威标题异步到达），
   等一次刷新后会统一。不影响使用。

## 六、《珊瑚海》专项实测（歌词配对 + 视频过滤）

### 6.1 视频过滤：搜索里混进大量非歌曲内容

实测搜索「珊瑚海」返回 14 条，其中至少 6 条不是可听的单曲：

| 结果 | 问题 |
|---|---|
| 逆转时间的公式就是珍惜当下.珊瑚海#戴上耳机#音乐 | vlog，不是歌 |
| 周杰伦、在专业录音棚听《珊瑚海》 | 闲聊/反应 |
| 珊瑚海周杰伦架子鼓动态鼓谱 | 鼓谱 |
| 珊瑚海周杰伦 / Sky光遇琴谱_瞳 | 游戏钢琴谱 |
| 珊瑚海_纯伴奏 | 伴奏 |
| 转身离开分手说不出来 / 2:02 | 歌词片段 |

**根因（两层）**：
1. `BilibiliSource.candidate(from:)` 里 `typeid` 按 `Int` 取、`tname` 取值——
   而 B 站搜索接口的 `typeid` 是**字符串**、字段名是 **`typename`**。
   两者都取不到 → **所有搜索结果都没有"音乐分区 +6"**，排序被播放量主导。
2. 乐谱/录音棚/戴耳机类关键词不在降权表里。

**修复**：
- 分区解析改为「优先 `typename` → 数字 `typeid` 且必须在音乐分区集合内」；
- `nonMusicKeywords` 增加：鼓谱 / 琴谱 / 动态鼓谱 / 架子鼓 / 五线谱 / 简谱 /
  录音棚 / 戴上耳机 / 纯伴奏 / 伴奏。

**实测对比**：修复后，正版《珊瑚海》（周杰伦&梁心颐）升到第 1、2 位；
vlog 从第 3 位降到第 7 位，鼓谱/琴谱降到 8/14 位。`SearchCandidateParsingTests` 4 条 + 排序测试 1 条。

### 6.2 歌词配对：其实是"滚动位置"错了

播放正版《珊瑚海》（前奏 13.8 秒）到 **0:04** 时，歌词区显示的是 **1:44 之后的副歌**：
「不够成熟坦白 / 热情不在 / 爱深埋珊瑚海 / 毁坏的沙雕如何重来…」——
看起来像"歌词配错了"，实际歌词文件是对的（第一行 `[00:13.79] 海平面远方开始阴霾`）。

**根因**：`LyricScrollLayout.make(currentIndex: nil)` 在没有当前行（还没唱到第一句）时，
把焦点取成 `contentHeight / 2`——**歌词正中间**。凡是前奏超过几秒的歌，
一开播就会显示中段歌词。

**修复**：没有当前行时对准**第一行**（`contentCenters.first`）。
`testNoCurrentLineAlignsToFirstLine` 替换了原来断言"居中"的测试（那条测试把 bug 固化了）。

**实测对比**：
- 修复前（0:04）：显示「不够成熟坦白 / 热情不在…」——见 `docs/evidence/walkthrough-coral-before.png`（截图已从公开仓库移除）
- 修复后（0:06）：显示「海平面远方开始阴霾 / 悲伤要怎么平静纯白 / 我的脸上 始终挟带…」，
  且歌词已由繁体转简体——见 `docs/evidence/walkthrough-coral-after.png`（截图已从公开仓库移除）

### 6.3 结论

- 歌词**内容**匹配正确（简繁也已转换）；
- 之前看到的"配对错误"是**前奏阶段的滚动定位 bug**；
- 视频过滤确实有问题，根因是分区字段解析错误 + 关键词缺失，已修并实测排序改善。

## 七、未播放/前奏时的歌词态（2026-11-16 追加）

**反馈**：截图里「说好的幸福呢」未播放时，歌词整块是灰的、没有高亮，看起来不对劲。

**原因**：没有当前行时 `model.lyric.index == nil`，布局把所有行都当"远处行"——
30% 不透明度 + 模糊，于是整块歌词没有重点。

**修复**：无当前行时回落到第 0 行（"即将唱的那句"），首行高亮、相邻两行淡出、其余隐藏。
实测 0:03 失败态下，首行「你的回话凌乱着 在这个时刻」清晰高亮。
证据：`docs/evidence/walkthrough-idle-lyrics.png`（截图已从公开仓库移除）。

另：该曲目上传者把标题写成「周杰伦-怎么了你累了」、歌手写成「《说好的幸福呢》」（倒装），
属于内容元数据问题，已记录待评估（与歌词无关）。
